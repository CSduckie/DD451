sceneLoaded 时序结论
LoadBootstrap 在发起 Bootstrap additive 加载前订阅 PrepareRuntimeTestScene；LootRuntimeManager.OnEnable 在 Bootstrap 实例创建时才订阅自己的 OnSceneLoaded。
因此本 fixture 的 Ruins sceneLoaded 回调排在 LootRuntimeManager 的回调前。当前 LootBox prefab 的 runtimeManager 初始为空，OnEnable 不会抢先 TryBind；Start 在 sceneLoaded 之后。
前述 Generated 断言会暴露未来场景改动或初始化顺序变化，不会悄悄继续依赖 50% 原概率。
死亡后的观察 handler 则是在运行中追加；它在 Loot handler 之后观察 Shelter，但关闭轮次 guard 已阻止旧 Ruins 认领，仍可证明加载当时清算完成。
