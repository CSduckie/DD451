四、预制体、配置与相机

Player逻辑根脚底为原点，缩放(1,1,1)。根只有一个Rigidbody和一个CapsuleCollider，胶囊Center(0,1,0)、Height2、Radius0.4；锁Z与全部旋转，使用Interpolate。表现胶囊和方向标记均无Collider。
CapsulePlaceholder负责可视压低和转身；CameraTarget为逻辑根直接子对象，位置(0,1.3,0)，不随表现旋转或缩放。
PlayerConfig试玩默认：moveSpeed5、crouchSpeed2、jumpSpeed7、planeZ0、HP3、受伤无敌0.5秒。地面SphereCast距离0.12、半径0.25、最小法线Y0.65；排除自身和Trigger，侧墙不算地面。详细Inspector说明见PlayerSetup。
按住C蹲伏、松开恢复；先站立再跳。只缩表现，不缩实体碰撞体，因此本轮不支持钻低矮通道，也没有起身穿顶问题。
真实场景运行发现默认物理摩擦会在贴平台侧面起跳时消耗Y速度。已给玩家胶囊接PlayerFrictionless物理材质：静/动摩擦0、Minimum组合、弹性0，并补真实平台回归；不是用Transform强行抬玩家。
输入引用现有Assets/Input/GameInputActions.inputactions，GUID 052faaac586de48259a63d0c4782560b。仅Clone四个动作运行实例，只启用Keyboard&Mouse组，不改资源、不关闭共享动作表。Move取X；Jump/Interact缓存按下，消费一次；Update读快照，FixedUpdate写物理。

Cinemachine实际版本3.1.7。PlayerCamera根挂小型Binder，OutputCamera含Camera、唯一AudioListener、URP附加相机数据、CinemachineBrain；SideFollow含CinemachineCamera与PositionComposer。

五、公开入口与协作边界

PlayerController：
- bool ResetForExploration(int roundId, Vector3 spawnPosition)：只接受更大的正数轮次，建立HP/输入/姿态/速度/出生Z/状态；同轮旧轮返回false。首次创建不自动准备，未准备HP0不发死亡。
- void SetBackpackOpen(bool)：清请求并限制主动操作，保持打开时的站/蹲姿态，保留重力/落地/受伤/死亡。关包不能解除IsDead限制。
- void SetInteractionUiBlocked(bool)：其他UI仅占用世界交互时使用。
- bool ChangeState(PlayerState)、PlayAnimation(string,float)、Position、FacingDirection(+1/-1)、IsCrouching、IsGrounded、IsPrepared、IsDead、CanAct、CurrentState、Body。
- event Action<Vector3> Teleported：相机瞬移通知。
PlayerHealth：精确实现现有IHealthTarget的int CurrentHealth、int MaxHealth、void Heal(int)。公开bool TakeDamage(int)，IsPrepared/IsDead/CurrentRound。
事件HealthChanged(int current,int max)、NonLethalDamaged(int actualDamage)、Died()。先落实生命/死亡限制再通知；死亡仅一次。治疗同步封顶，非正数无效，死亡不复活，无敌不阻止治疗。
每个显示订阅者异常局部捕获并记录，其他通知继续，01的计次不被中断；生命回调期间拒绝重入伤害/治疗/新轮次。外部只通过Controller准备新轮次，不独立重置Health。
Interactable：PromptKey、CanInteract(PlayerInteraction)、Interact(PlayerInteraction)。PlayerInteraction：CurrentTarget/CurrentPromptKey、RefreshTarget、TryInteract、SetInputBlocked。
选最近合法Collider表面的目标，同距离按实例ID，目标多个Collider去重；限制目标根Z差，实体遮挡阻止交互；按E执行前同步物理并再验证范围、启用、销毁、CanInteract。目标不自行监听E。
