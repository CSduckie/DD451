Shared behavior and minimal API
- Enter object interaction TriggerBox: eligible for E prompt. Press E once: invoke existing target action once. Enter alone does not auto-loot or auto-open.
- A dedicated 3D BoxCollider with isTrigger=true defines the range; inspector center/size are configurable independently of model scale and solid collision.
- Prefer named child TriggerBox; existing solid model collider remains non-trigger if it provides blocking. Ground props need no added solid body merely to enable interaction.
- Use player body CapsuleCollider overlap as this assignment's explicit boundary convention, not mesh contact. Range trigger never pushes or blocks the player.
- No extra legacy 2m radius dilation/cutoff or target-root 0.65 Z clipping for explicitly configured TriggerBox. Its authored shape and depth decide eligibility. Trigger-only depth overlap can permit models with visual Z offsets.
- Preserve actual wall obstruction. Ray to a defined interactionPoint/target anchor, NOT TriggerBox.ClosestPoint when player is already inside, which would produce zero-length rays and bypass walls.
- Stable target selection by distance to interaction point; deterministic tie-break. One target/action per E; no multi-open when ranges overlap.
- A disabled/destroyed target or disabled trigger immediately invalidates eligibility; player spawn/teleport inside, re-enable and multiple body colliders must work without waiting for a new OnTriggerEnter.
- Keep UI/input locking separate from spatial eligibility. An opened loot UI blocks another E but must not invalidate its own CanReachTarget check. Leaving range cancels current drag/search safely; revealed items remain, current unrevealed timer restarts on reopen.
- Keep CanReachWorldPoint for actual world-point/drop validation. It currently serves LootRuntimeManager.IsDropPointSafe and has no target object; do not remove it or let its old radius clamp TriggerBox target reach.
- Proposed shared fields owned by 02 on Interactable: public BoxCollider interactionTrigger; optional public Transform interactionPoint. Fallback point must be documented. Keep existing CurrentTarget, CurrentPromptKey, TryInteract, CanReachTarget, CanReachWorldPoint consumer APIs where possible.
- If 02 finds this minimal field proposal unsuitable, update 02A handoff with the exact replacement before dependent writes. No generic interaction framework or duplicate E input.
- All project-owned C# has no namespace, English folders, existing readable style. Reuse user's local GitHub reference where relevant. 3D physics only, 1920x1080, default CN / existing F10 EN service.
